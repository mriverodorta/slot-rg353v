# Controls and shortcuts

Installed modules and System → Features can hide or disable actions. Controls can be remapped; this table describes the default assignments, not a forced layout.

## Shelf and menus

![Shelf controls configuration](images/features/controls-shelf.png)

Use Left/Right to browse cartridges, **L1/R1** to switch shelves and **Y** to toggle a favorite with the default layout. The current cartridge's name appears briefly, then fades. A opens the selected game. In menus, Up/Down selects, A opens/confirms, B goes back, and Left/Right changes a selected value. Holding a direction repeats through longer menus. Follow the displayed button legends for context-specific actions such as core selection.

Tap F during a game to open the pause/settings menu; double-F accesses States. Hold F to eject and return to the shelf, saving resume progress. Hold A while launching a game to bypass automatic resume and reach the game's normal boot/title sequence. This does not erase its battery save.

The left analog stick can provide directional movement; the D-pad remains usable. GBA A/B, Start/Select and L/R retain their game meanings unless part of a shortcut.

## In-game defaults

| Combination | Action |
| --- | --- |
| Select + R1 | Create a manual save state |
| Select + L1 | Load the quick/manual state |
| Select + A / B | Next / previous shader |
| Select + Y | Change color correction |
| Select + R2 / L2 | Next / previous GB palette |
| Select + X | Toggle the small integer frame counter |
| Select + Start | Take a screenshot |
| Hold R2 | Fast-forward |
| Hold L2 | Rewind |
| Select + Up / Down | Brightness up / down |
| Select + Left / Right | Blue-light filter down / up |

Volume buttons control the active speaker/headphone volume. The frame counter reports delivered/rendered game frames; a game's original timing is about 59.7 Hz, and a fast-forward mode may intentionally skip presentation. The counter is not a direct measure of every emulated frame.

System → Features separates the state browser from manual shortcuts, and allows disabling Favorites, core selection, fast-forward, rewind and in-game shader/palette/color changes. Disabling an in-game change preserves the selected setting. There is no Settings PIN or separate game-only preset.

Use Controls to change supported game bindings and shortcuts. Resolve conflicts shown by the menu. If a shortcut appears inactive, first check its installed module and corresponding System → Features toggle.

![Shortcut configuration](images/features/controls-shortcuts.png)

![Console button configuration](images/features/controls-game.png)

Open **Controls → Console Buttons**, **Shortcuts** or **Shelf Buttons**. Select the action and press A to record a replacement, then follow the on-screen button hints. Use the recording page's cancel/reset actions if you change your mind. The Help menu reflects available features and the installed controls.
